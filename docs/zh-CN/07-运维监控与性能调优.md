| **检索 P99 延迟** | > 500 ms | 30 s | `app.py` `perf_counter` / Prometheus `histogram_quantile` |
| **检索错误率** | > 1% / 5min | 60 s | 结构化日志 `level=ERROR` |
| **数据库连接池使用率** | > 80% | 30 s | `pg_stat_activity` / 连接池指标 |
| **磁盘使用率** | > 85% | 5 min | `df -h` / `pg_database_size` |
| **内存使用率** | > 90% | 60 s | `psutil` / `node_exporter` |
| **GPU 显存使用率** | > 95% | 60 s | `rocm-smi` / `nvidia-smi` |
| **LLM 服务可用性** | < 99.9% | 60 s | `/v1/models` 健康检查 |

### 7.1.2 关键业务指标 (趋势观测)

| 指标 | 用途 | 采集方式 |
|------|------|----------|
| **日检索次数** | 容量规划 | `app.py` 计数器 / Prometheus `counter` |
| **向量覆盖率** | `embedded / total` | 定时 SQL `COUNT(embedding IS NOT NULL) / COUNT(*)` |

## 7.4 数据库性能调优

### 7.4.1 索引维护策略

| 操作 | 频率 | 命令 | 影响 |
|------|------|------|------|
| **GIN 索引并发重建** | 周末低峰 | `REINDEX INDEX CONCURRENTLY idx_novel_tropes_gin;` | 无锁，仅 CPU/IO |
| **HNSW 索引重建** | 月度/数据漂移 | `REINDEX INDEX idx_novel_hnsw;` | **独占锁**，需维护窗口 |
| **统计信息更新** | 自动/每日 | `ANALYZE novel_catalog;` | 极轻，可频繁 |
| **VACUUM (FULL)** | 月度/膨胀 > 20% | `VACUUM (FULL) novel_catalog;` | **独占锁**，需维护窗口 |

### 7.4.2 HNSW 参数运行时调优
```sql
-- 查询会话级调优 (仅影响当前会话)
SET hnsw.ef_search = 200;  -- 默认 40，召回率提升，延迟微增

-- 验证当前值
SHOW hnsw.ef_search;

-- 永久生效 (postgresql.conf)
hnsw.ef_search = 200
```
| `ef_search` | 召回率 (近似) | 延迟增加 | 适用场景 |
|-------------|--------------|----------|----------|
| 40 (默认) | ~95% | 基准 | 高吞吐、容忍少量漏召 |
| 100 | ~98% | +20% | 平衡 |
| 200 | ~99.5% | +50% | 高召回优先 |
| 400 | ~99.9% | +100% | 离线批量/评测 |

### 7.4.3 连接池配置
```python
# psycopg2.pool.ThreadedConnectionPool
pool = ThreadedConnectionPool(
    minconn=2,
    maxconn=20,
    **db_conn_info()
)

# 获取连接
conn = pool.getconn()
try:
    with conn.cursor() as cur:
        cur.execute(...)
finally:
    pool.putconn(conn)
```
| 参数 | 推荐值 | 依据 |
|------|--------|------|
| `minconn` | 2 | 保持热连接，减少冷启动 |
| `maxconn` | CPU 核心数 × 2 | 避免 PostgreSQL `max_connections` 耗尽 |
| `connect_timeout` | 10s | 避免长时间阻塞 |
| `keepalives_idle` | 30 | 防止防火墙/NAT 断开空闲连接 |

## 7.5 模型服务调优

### 7.1 llama.cpp 启动参数调优
```bash
# 针对 Qwen2.5-27B Q6_K @ RDNA 3.5 (gfx1151) 优化
./llama-server \
  -m models/qwen2.5-27b-instruct-q6_k.gguf \
  -c 8192 \           # 上下文窗口，按需增大
  -ngl 99 \           # 全层卸载到 GPU
  -ub 512 \           # 用户批大小
  -b 512 \            # 批大小
  -fa \               # Flash Attention (若支持)
  --mlock \           # 锁定内存防 swap
  --no-mmap \         # 禁用 mmap (ROCm 下更稳)
  --port 8080 \
  --host 127.0.0.1
```

| 参数 | 说明 | 调优方向 |
|------|------|----------|
| `-b` / `-ub` | 批大小 | 显存允许增大至 1024/2048 提升吞吐 |
| `-c` | 上下文窗口 | 按需增大，显存线性增长 |
| `--mlock` | 锁内存 | 防止 swap 导致延迟抖动 |
| `--no-mmap` | 禁用 mmap | ROCm 下避免页错误延迟抖动 |
| `-fa` | Flash Attention | 若硬件支持，显著提升长上下文速度 |

## 7.3 容量规划表

| 数据规模 | 向量内存 (HNSW) | 磁盘 (表+索引) | 内存建议 | GPU 显存 | 预估 QPS |
|----------|----------------|----------------|----------|----------|----------|
| 1 万 | ~150 MB | ~500 MB | 8 GB | 8 GB | 50 |
| 10 万 | ~1.5 GB | ~5 GB | 16 GB | 12 GB | 30 |
| 100 万 | ~15 GB | ~50 GB | 64 GB | 24 GB | 20 |
| 1000 万 | ~150 GB | ~500 GB | 256 GB | 48 GB+ (多卡) | 15 |

> **经验法则**：HNSW 内存 ≈ `向量数 × 维度 × 4 字节 × 1.5 (图结构开销)`；磁盘 ≈ 内存 × 3-4 (含 WAL、索引、TOAST)。

## 7.4 自动化运维脚本

### 7.4.1 每日巡检脚本 (`daily_check.sh`)
```bash
#!/bin/bash
set -euo pipefail

LOG="/var/log/novel-aip/daily_$(date +%F).log"
exec > >(tee -a "$LOG") 2>&1

echo "=== $(date) Daily Check ==="

# 1. 服务存活
for svc in postgresql llama-cpp streamlit; do
    systemctl is-active --quiet $svc && echo "✅ $svc active" || { echo "❌ $svc DOWN"; exit 1; }
done

# 2. 端口可达
for port in 5432 8080 8501; do
    nc -z localhost $port && echo "✅ Port $port open" || echo "❌ Port $port CLOSED"
done

# 3. 磁盘空间
df -h / | awk 'NR==2 {print "Disk: " $5 " used (" $4 " free)"}'

# 4. 内存/显存
free -h | awk 'NR==2 {print "RAM: " $3 "/" $2}'
rocm-smi --showmemuse vram 2>/dev/null | head -5

# 5. 数据库连接数
psql -U postgres -d fileindex -tAc "SELECT count(*) FROM pg_stat_activity;" | xargs -I{} echo "DB Connections: {}"

# 6. 表大小
psql -U postgres -d fileindex -c "SELECT pg_size_pretty(pg_relation_size('novel_catalog')) AS table_size, pg_size_pretty(pg_total_relation_size('novel_catalog')) AS total_size;"

# 7. 最近 1 小时错误率
ERRORS=$(journalctl -u novel-aip --since "1 hour ago" -p err --no-pager | wc -l)
echo "Recent errors (1h): $ERRORS"

echo "=== Check Complete ==="
```

### 7.4.2 定时任务 (crontab)
```cron
# 每日 02:00 巡检
0 2 * * * /opt/novel-aip/scripts/daily_check.sh >> /var/log/novel-aip/daily_check.log 2>&1

# 每周日 03:00 GIN 索引并发重建
0 3 * * 0 psql -U postgres -d fileindex -c "REINDEX INDEX CONCURRENTLY idx_novel_tropes_gin; REINDEX INDEX CONCURRENTLY idx_novel_genres_gin; REINDEX INDEX CONCURRENTLY idx_novel_main_characters_gin; REINDEX INDEX CONCURRENTLY idx_novel_key_locations_gin;"

# 每月 1 日 04:00 HNSW 索引重建 + VACUUM FULL
0 4 1 * * psql -U postgres -d fileindex -c "REINDEX INDEX idx_novel_hnsw; VACUUM (FULL) novel_catalog; ANALYZE novel_catalog;"
```

## 7.5 性能基准回归测试

### 7.5.1 基准测试脚本 (`benchmark.py`)
```python
#!/usr/bin/env python3
import time, statistics, psycopg2, os
from sentence_transformers import SentenceTransformer

QUERIES = [
    "奇幻玄幻 主角重生 复仇",
    "都市异能 系统流 打脸",
    "历史穿越 权谋 皇帝",
    "科幻 星际 机甲 进化",
    "悬疑 推理 密室 杀人",
]

def benchmark():
    embedder = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5")
    conn = psycopg2.connect(**db_conn_info())
    
    latencies = []
    for q in QUERIES * 20:  # 100 次查询
        vec = embedder.encode(["search_query: " + q])[0]
        vec_str = "[" + ",".join(f"{v:.8f}" for v in vec) + "]"
        
        start = time.perf_counter()
        with conn.cursor() as cur:
            cur.execute("""
                SELECT 1 - (summary_embedding <=> %s::vector) AS score
                FROM novel_catalog
                WHERE summary_embedding IS NOT NULL
                ORDER BY score DESC LIMIT 5
            """, (vec_str,))
            _ = cur.fetchall()
        latencies.append((time.perf_counter() - start) * 1000)
    
    print(f"Queries: {len(latencies)}")
    print(f"P50: {statistics.median(latencies):.2f} ms")
    print(f"P95: {statistics.quantiles(latencies, n=20)[18]:.2f} ms")
    print(f"P99: {statistics.quantiles(latencies, n=100)[98]:.2f} ms")
    print(f"Mean: {statistics.mean(latencies):.2f} ms")

if __name__ == "__main__":
    benchmark()
```

### 回归判定标准
| 指标 | 基线 | 回归阈值 | 动作 |
|------|------|----------|------|
| P99 延迟 | 80 ms | > 200 ms | 立即告警，回滚/扩容 |
| P50 延迟 | 30 ms | > 100 ms | 告警，排查索引/连接池 |
| 错误率 | 0% | > 0.1% | 立即告警 |
